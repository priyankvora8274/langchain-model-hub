# LangChain Model Hub 🤖

A collection of Python examples exploring different AI models using **LangChain**, including Large Language Models (LLMs), Chat Models, and Embedding Models.

## 📌 Project Overview

This repository demonstrates how to integrate and experiment with AI models using LangChain for Generative AI applications.

## 📂 Repository Structure

- **LLMs/** – Working with Large Language Models for text generation.
- **ChatModels/** – Exploring conversational AI and chat-based interactions.
- **Embedding_models/** – Generating vector embeddings for semantic search and AI applications.

## 🛠️ Tech Stack

- Python
- LangChain
- Large Language Models (LLMs)
- Chat Models & Embeddings

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/priyankvora8274/langchain-model-hub.git
cd langchain-model-hub
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Configure the required API keys using environment variables before running the examples.

## 🎯 Learning Objectives

Understand different model types, explore LangChain integrations, and build a foundation for Generative AI, chatbots, and RAG applications.
